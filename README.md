# Nonprofit Bloom Starter

A beginner-friendly starter template for a modern institute/nonprofit website built with:

- Next.js App Router
- TypeScript
- Tailwind CSS
- Reusable React components

## Included pages

- Home
- About
- Programs
- Research
- Events
- Team
- Membership

## Quick start

```bash
npm install
npm run dev
```

## Project structure

- `app/` - route-based pages using the App Router
- `components/layout/` - reusable layout primitives (navbar, footer, section)
- `components/ui/` - reusable UI elements (button, card)
- `lib/` - shared configuration and CMS integration placeholders
